# Этап 5 — Telegram WS, нижняя навигация, авто-перезапуск

APK 0.5.0. Проверка на реальном телефоне (arm64).

## 1. Четыре раздела

- [ ] Внизу постоянная полоса: **Главная**, **Telegram**, **Настройки**, **Логи**.
- [ ] Полоса остаётся на месте при прокрутке.
- [ ] Переключение разделов не теряет VPN.
- [ ] На Главной — кнопка включения, статус, трафик, короткий журнал (6 строк).
- [ ] В Telegram — только WS-прокси.
- [ ] В Настройках — приложения и домены.
- [ ] В Логах — полный журнал.
- [ ] После Логи → Главная подсвечена именно Главная, не Настройки.

## 2. Telegram WS-прокси

- [ ] Раздел **Telegram** → **Запустить**.
- [ ] Статус «Работает на 127.0.0.1:1443».
- [ ] Показан секрет вида `dd...` / `ee...`.
- [ ] Нажать **Применить в Telegram** → Telegram открывается с предложением
      добавить прокси. Подтвердить.
- [ ] Если Telegram не открылся — **Копировать ссылку** и добавить вручную:
      Настройки → Данные и память → Прокси → Добавить.
- [ ] В Telegram появляется прокси `127.0.0.1:1443`, сообщения отправляются.
- [ ] **Остановить** — статус «Остановлен», уведомление исчезает.
- [ ] Повторный запуск работает.

> На эмуляторе x86_64 модуль покажет ошибку: в APK есть
> `libtgwsproxy.so` только для arm64-v8a и armeabi-v7a.

## 3. Per-App и авто-перезапуск

- [ ] Включить VPN.
- [ ] Настройки → Приложения → **Только выбранные** → выбрать 1–3 приложения.
- [ ] VPN **подключается**, в логе нет `addAllowedApplication already called`.
- [ ] Выбранные приложения работают, остальные — напрямую.
- [ ] Настройки → Домены → добавить `x.com` → Сохранить.
- [ ] VPN сам перезапускается, в журнале `Перезапуск VPN после изменения
      настроек`, затем `VPN работает`.
- [ ] Если VPN был выключен, сохранение просто пишет настройки без запуска.

## 4. X / Twitter

- [ ] Открыть X, обновить ленту, открыть профиль, видео/картинки.
- [ ] Если сразу не открылось — подождать 1–3 минуты: AUTO перебирает
      варианты X (`AUTO x: ... index=` в журнале).
- [ ] В журнале для `x.com`, `api.x.com`, `pbs.twimg.com`,
      `video.twimg.com` должна быть группа X, а не общий fallback.
- [ ] В отчёте есть `autostate.x` и строка `telegram`.

## 5. YouTube и Telegram на чужом устройстве

- [ ] YouTube: проверить 1080p/1440p, а не только 480p.
- [ ] В `ciadpi.log` не должно быть `new conn: ... addr=2001:...` для
      googlevideo/youtubei (после `-X` upstream IPv4).
- [ ] Telegram: посмотреть в журнале `TelegramProxy: stats:`.
- [ ] Если пинг высокий — Telegram → выключить **Cloudflare fallback**,
      остановить и снова запустить прокси.
- [ ] Если Telegram перестал подключаться — включить fallback обратно.

## 4. Совместимость

- [ ] YouTube-видео и Discord работают как раньше.
- [ ] AUTO-ротация `yt/dc` продолжает работать.
- [ ] Telegram WS-прокси не ломает VPN (они независимы).
- [ ] Остановка VPN не останавливает Telegram WS-прокси, и наоборот.
- [ ] После перезагрузки телефона настройки сохраняются, прокси нужно
      запустить вручную.

## 5. Если что-то не так

«Скачать» в Логах. В отчёте будут:

- `Telegram WS-прокси` строки запуска/остановки;
- `Перезапуск VPN после изменения настроек`;
- `Per-App`, `user hosts`, `autostate.*`;
- хвосты `ciadpi.log` / `hev.log`.

Прислать файл + что именно не сработало.
