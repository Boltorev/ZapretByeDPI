# Этап 3 — per-host стратегии и AUTO-ротация

Проверяем на реальном телефоне APK 0.3.0.

## 1. Запуск

- [ ] Установить 0.3.0 (при необходимости удалить старую версию).
- [ ] Включить VPN, дождаться `РАБОТАЕТ`.
- [ ] Пресет — `PER_HOST_YT` (или `PER_HOST_YT_TLSREC`).
- [ ] В журнале: `QUIC fake готов: 1200 байт`,
      `Выбрана стратегия PER_HOST_YT`,
      `канарейка запущена: fails=4, time=45s`.

## 2. YouTube

- [ ] Открывается главная, поиск, подписки.
- [ ] Видео запускается и идёт без бесконечной загрузки.
- [ ] Перемотка работает.
- [ ] В `Stats` растут `rx_packets` (видео идёт через QUIC/TCP).

## 3. Discord

- [ ] Открывается `discord.com` в браузере.
- [ ] Приложение Discord подключается (если установлено).

## 4. AUTO-ротация

- [ ] Оставить VPN включённым на 3–5 минут.
- [ ] В журнале каждые 10 секунд появляются `Auto yt/dc ... OK`
      или `FAIL n/4`.
- [ ] Если были 4 отказа — `AUTO yt: ... -> ...`, `Ротация: ciadpi
      перезапущен`, счётчик «Ротаций» увеличился.
- [ ] После ротации интернет и YouTube продолжают работать
      (кратковременный разрыв соединений допустим).

Проверить сохранение состояния:

```bash
adb shell run-as com.zapret.byedpi cat shared_prefs/zapret_prefs.xml
```

Там должны быть `autostate.yt` и `autostate.dc`.

## 5. Остановка

- [ ] Выключить VPN — статус «Остановлен», канарейка остановлена.
- [ ] Включить снова — поднимается без перезагрузки.

## 6. Если что-то не работает

Нажать **«Скачать»** в журнале. В отчёте будут:

- `preset`, `rotations`, `autostate.yt`, `autostate.dc`;
- полный AppLog с `Auto`, `AUTO`, `Ротация`;
- хвосты `ciadpi.log` и `hev.log`.

Прислать файл + что именно не открылось.

## Что считается успехом этапа 3

- YouTube-видео играет через `PER_HOST_YT` + QUIC fake.
- Discord открывается.
- Канарейка работает, состояние `autostate` пишется.
- При искусственном/реальном сбое стратегия меняется без пересоздания VPN.
