# Этап 4 — Per-App VPN, домены, полный журнал

APK 0.4.0, Android 8+.

## 1. Запуск

- [ ] Установить 0.4.0.
- [ ] Открыть приложение: появился блок **НАСТРОЙКИ** с кнопками
      «Приложения», «Домены», «Открыть».
- [ ] Включить VPN, YouTube и Discord работают как на 0.3.0.

## 2. Per-App VPN

### Только выбранные

- [ ] «Приложения» → «Только выбранные».
- [ ] Отметить браузер (Chrome/Firefox).
- [ ] Сохранить, выключить и снова включить VPN.
- [ ] Браузер ходит через туннель (YouTube открывается).
- [ ] Другое приложение (например, Telegram) идёт напрямую.
- [ ] В журнале: `Per-App ONLY: включено пакетов 1`.

### Все, кроме выбранных

- [ ] «Все, кроме выбранных» → отметить Telegram.
- [ ] Перезапустить VPN.
- [ ] Telegram идёт напрямую, остальные — через VPN.
- [ ] В журнале: `Per-App EXCEPT: исключено пакетов 1`.

### Все

- [ ] Вернуть «Все приложения», перезапустить VPN.
- [ ] Туннелируются все, кроме самого ZapretByeDPI.

## 3. Свои домены

- [ ] «Домены» → добавить `example.com` (или свой домен).
- [ ] Сохранить, перезапустить VPN.
- [ ] В журнале `ciadpi` появилась группа `-H ":example.com"` и
      `Пользовательских доменов: 1`.
- [ ] Домен открывается через туннель.
- [ ] «Пример» заполняет YouTube/Discord-домены, «Очистить» удаляет.

## 4. Полный журнал

- [ ] «Открыть» в блоке настроек.
- [ ] Видны все записи, а не 14 строк.
- [ ] Поиск по тексту/тегу фильтрует.
- [ ] Фильтр по уровню (DEBUG/INFO/WARN/ERROR) работает.
- [ ] «Копировать» кладёт видимые строки в буфер.
- [ ] «Очистить» спрашивает подтверждение.
- [ ] «Скачать» сохраняет полный диагностический отчёт.

## 5. Регрессии

- [ ] AUTO-ротация `yt/dc` продолжает работать (лог `Auto ... OK/FAIL`,
      `autostate.*`).
- [ ] Видео YouTube не виснет.
- [ ] Остановка VPN убирает уведомление и ключ.
- [ ] Повторный запуск не требует перезагрузки.

## 6. Если что-то не так

«Скачать» в журнале. В отчёте будут:

- `Per-App` строки;
- `Пользовательских доменов: N`;
- аргументы ciadpi с `-H`;
- полный AppLog и хвосты `ciadpi.log` / `hev.log`.

Прислать файл + описание, что выбрано и что не работает.
