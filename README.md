# ZapretByeDPI

Приложение для Android, которое возвращает доступ к YouTube, Discord, X (Twitter)
и другим сайтам, если оператор их замедляет или блокирует.

Без root, без аккаунтов и подписок. Одна кнопка — и всё работает.

---

## Что оно делает

Многие операторы связи анализируют трафик (это называется DPI) и режут
неудобные им сайты. Приложение обходит это прямо на телефоне: трафик идёт
мимо блокировок, но **не через чужой VPN-сервер** — ваши данные не уходят
третьим лицам (исключение — встроенный прокси для Telegram, он ходит через
Cloudflare, об этом ниже).

- **Одна кнопка.** Нажали «Подключить» — приложение само подбирает рабочий
  способ обхода и запоминает его.
- **YouTube, Discord, X.** Для каждого сервиса свои настройки, а не один
  общий режим «для всего».
- **Не нужно ничего выбирать руками.** Все способы обхода перебираются
  автоматически.
- **Смена сети не ломает подключение.** Переключились с Wi-Fi на мобильные
  данные — приложение само перезапустит обход.
- **Свои приложения.** Можно гонять через обход только выбранные программы,
  например только браузер и YouTube.
- **Свои сайты.** Если оператор режет ещё что-то, домен можно добавить
  в списки вручную.
- **Журнал.** Видно, что происходит: подключился, подбирает, ошибка — и
  можно выгрузить отчёт, если нужна помощь.
- **Telegram отдельно.** На вкладке «Telegram» есть встроенный прокси для
  Telegram, если он не грузит сообщения и медиа.

## Установка

1. Откройте раздел **Releases** этого репозитория и скачайте APK.
   - Для обычного телефона — **arm64-v8a**.
   - Не знаете, какой выбрать — берите **universal** (поставится на любое
     устройство, просто весит больше).
   - `x86` / `x86_64` — только для эмуляторов Android на компьютере.
2. Откройте скачанный файл. Android спросит разрешение на установку из
   этого источника — разрешите.
3. Если раньше стояла другая версия с другим ключом подписи, Android
   попросит её удалить. Это нормально.

Нужен Android 8.0 или новее.

> APK подписаны тестовым ключом разработчика, поэтому Android может
> показать предупреждение «неизвестный источник». Это ожидаемо: приложение
> собирается из этих же исходников, магазин приложений не используется.

## Первый запуск

1. Откройте приложение и нажмите большой круг **«Подключить»**.
2. Android спросит разрешение на VPN — разрешите. Это системный запрос,
   без него обход невозможен.
3. На Android 13+ ещё спросит разрешение на уведомления — можно разрешить,
   чтобы видеть состояние в шторке.
4. Подождите несколько секунд: в журнале на главной будет видно, как
   приложение подбирает рабочий способ обхода.
5. Когда статус станет **«Работает»** — открывайте YouTube, Discord, X.

Остановка — тем же кругом. Ничего настраивать не обязательно: всё уже
включено по умолчанию.

## Что можно настроить (по желанию)

| Раздел | Зачем |
|---|---|
| **Настройки → Приложения** | Гонять через обход только выбранные программы |
| **Настройки → Домены** | Добавить сайт, который у вас блокируется, но его нет в списках |
| **Telegram** | Встроенный прокси для Telegram (см. ниже) |
| **Логи** | Полный журнал и экспорт отчёта |

После изменения списков приложений или доменов перезапускать VPN вручную
не нужно — приложение сделает это само.

### Telegram

1. Откройте вкладку **Telegram** и нажмите **«Запустить»**.
2. Нажмите **«Применить в Telegram»** — откроется Telegram с предложением
   добавить прокси, подтвердите.
3. Прокси работает отдельно от кнопки VPN: Telegram можно ускорять, даже
   когда обход выключен.

Технически этот прокси ходит через Cloudflare — это сторонний сервис,
и только для Telegram. Остальной трафик через него не идёт.

**Канал.** До Cloudflare можно достучаться двумя способами: `TLS 443`
(как обычный HTTPS) и `HTTP 80` (запасной). Какая дорога открыта —
зависит от сети: на мобильном интернете обычно проходит TLS 443, на
домашнем Wi-Fi бывает только HTTP 80. Приложение проверяет канал при
запуске (несколько секунд) и **само переключается**, если данных нет;
рабочий канал запоминается отдельно для Wi-Fi и для мобильной сети.
Текущий канал виден в карточке «Канал» и в уведомлении. Там же можно
выбрать канал вручную кнопками `TLS 443` / `HTTP 80` — выбор запомнится
для этой сети.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Кнопка не включается, пишет про VPN | Закройте другой VPN или отключите «Always-on VPN» в настройках Android, затем нажмите ещё раз |
| Включается, но сайты не открываются | Проверьте, что интернет работает без VPN; попробуйте переключиться на мобильные данные и обратно |
| YouTube открывается, видео не грузится | Подождите 10–20 секунд: приложение подбирает способ под ваш оператор; затем перезапустите VPN |
| Пропало после сна экрана | Разблокируйте телефон, откройте приложение и нажмите «Подключить», если статус не «Работает» |
| Telegram-прокси не запускается | Проверьте, что это телефон/планшет на ARM (на эмуляторе x86 прокси недоступен, VPN при этом работает) |
| Совсем ничего не помогает | Откройте «Логи» и нажмите экспорт — пришлите файл, по нему видно причину |

## Чего ждать не стоит

- **Это не анониматор.** Приложение обходит замедление конкретных сайтов,
  но не скрывает ваш IP и не заменяет полноценный VPN для приватности.
- **У разных операторов — разные блокировки.** Автоподбор покрывает
  типичные случаи, но в редких сетях может не сработать.
- **Root не нужен** — и не требуется ничего дополнительно устанавливать.
